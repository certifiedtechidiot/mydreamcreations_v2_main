## 🎨 Theme Overview & Aesthetic
This theme replicates the calm, high-end editorial styling of Pinterest Pin `1133570168748936587`:
- **Palette**: Warm ivory (`#FAF8F5`), organic ribbon sand (`#F4F1EA`), deep forest olive (`#384A3E`), charcoal (`#1E211A`), and subtle antique gold (`#C4A468`).
- **Typography**: 
  - *Serif Headlines*: `Cormorant Garamond` (classic, timeless luxury)
  - *Body & Nav*: `Plus Jakarta Sans` (crisp, modern legibility)
  - *Script Accent*: `Alex Brush` (*"More Than Events"* handwritten flair)
- **Visuals & Dynamic Effects**:
  - Seamless timed crossfade hero background slideshow
  - 4-pillar capability ribbon with clean architectural line icons
  - 4 event category cards with subtle zoom and border transitions
  - Asymmetric 3-frame latest creations showcase with timed image rotations
  - 4-step linear numbered process timeline
  - Client testimonial slider with animated quote transitions
  - Direct WhatsApp consultation modal with pre-formatted inquiry text
  - Sticky glassmorphic floating header with scroll-reactive styling

## 🚀 How to Run Locally
No build tools or bundlers required. Simply run any local static HTTP server:

```bash
# Using Python 3
python3 -m http.server 8080

# Or using Node.js npx
npx serve .
```
Then visit `http://localhost:8080` in your web browser.

---

## 🌐 Deploy to GitHub Pages
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment**, select source: **Deploy from a branch**.
3. Choose branch **`main`** and folder **`/ (root)`**.
4. Click **Save** — the live site will be live within seconds.
